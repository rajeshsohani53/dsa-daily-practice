# DSA Daily Practice - Java

A day-by-day DSA practice repo in Java, covering two pointers, sliding window, sorting, string problems, and more.

---

## Folder Structure

### Day01 - Two Pointer: Two Sum
| File | Description |
|------|-------------|
| `Day01_TwoPointer_TwoSum.java` | Find pair with given sum using two pointer |

| File | Description |

### Day06 - Sorting
| File | Description |
